Algorithm Lab Notes

The Naive String Matching Algorithm checks for the presence of a pattern within a text by sliding the pattern across the text one character at a time.

  • Step-by-step: Compares character by character. If a mismatch occurs, it shifts the pattern exactly one position to the right and starts checks over.
  • Worst-case complexity: $O((N - M + 1) \cdot M)$ comparisons. This occurs when both the text and the pattern consist of the same repeated characters (e.g., Text = "AAAAAAAB", Pattern = "AAAB").
  • Best-case complexity: $O(N)$ operations. Occurs when mismatches occur immediately on the first character comparison, resulting in a single comparison per shift.
