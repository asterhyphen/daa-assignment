Floyd-Warshall Lab Notes

The Floyd-Warshall Algorithm calculates the shortest path between every pair of vertices in a weighted graph.

  • Dynamic Programming: Solves subproblems by gradually allowing more vertices to act as intermediate hops along a path.
  • Time Complexity: $O(V^3)$ operations due to three nested loops. It is highly efficient for dense graphs with many query paths.
  • Reconstruction: Using the predecessor matrix $P[i][j]$, we trace backwards from destination to source to draw the optimal routes.
